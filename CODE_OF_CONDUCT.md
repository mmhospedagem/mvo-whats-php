# Código de conduta

Este projeto recebe pessoas com diferentes experiências, origens e níveis de conhecimento. Trate participantes com respeito, discuta ideias com argumentos e ajude a manter exemplos acessíveis para quem está começando.

Não são aceitos assédio, ameaças, discriminação, exposição de dados pessoais, publicação de credenciais ou ataques direcionados a participantes. Discordâncias técnicas devem permanecer focadas no código e no comportamento observado.

Os mantenedores podem editar ou remover conteúdo que viole essas regras e limitar a participação quando necessário. Para comunicar uma situação sem expor pessoas publicamente, use o contato comercial divulgado em [mvo.host](https://www.mvo.host/) e identifique o repositório.
