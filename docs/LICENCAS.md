# Licença e avisos

A licença MIT das contribuições e da integração MVO está no arquivo [LICENSE](../LICENSE). As partes adaptadas conservam os copyrights e os termos originais reunidos em [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md), que acompanha a distribuição.

As dependências Composer, as fontes dos docs e os componentes nativos opcionais mantêm suas próprias licenças. A licença integral das fontes fica em [assets/fonts/OFL.txt](assets/fonts/OFL.txt). Os instaladores preservam os avisos completos junto aos binários em `.dev/native`.

A conexão, a autenticação, a persistência de sessão e as mensagens executam em PHP. Codecs e WebRTC opcionais podem usar componentes C; as ferramentas de geração de documentação e dados são usadas no desenvolvimento. Os checkouts de referência foram arquivados fora do projeto e não são necessários para instalar ou executar a biblioteca.

Este guia resume onde consultar os documentos legais. Os termos completos permanecem nos arquivos indicados acima.
