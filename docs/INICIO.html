Introdução

Conecte contas WhatsApp, mantenha sessões e integre mensagens à sua aplicação com o MVO WHATS PHP.

O SDK executa o protocolo e o loop de conexão em PHP. Você controla os eventos e os serviços da conta pelo namespace MVO\, com instalação pelo Composer.

Instale a biblioteca

No diretório da sua aplicação, execute:

composer require "mmhospedagem/mvo-whats-php:^1.0"

Use PHP 8.2+ de 64 bits, Composer 2 e as extensões declaradas no pacote. O guia de instalação mostra a configuração no Ubuntu e no Windows, os requisitos completos e as dependências opcionais de mídia e chamadas.

Conecte, receba e envie

Salve o primeiro exemplo como conectar.php na raiz da aplicação e execute php conectar.php. Escaneie o QR em WhatsApp → Aparelhos conectados → Conectar um aparelho. Depois, explore as abas de recebimento e envio.

conectar.php
<?php
require __DIR__.'/vendor/autoload.php';

use MVO\Auth\QrCode;
use MVO\WaClient;

$client = new WaClient(
    sessionId: 'minha-sessao',
    authDirectory: __DIR__.'/var/whatsapp-auth',
);
$client->on('auth_qr', static function (array $event): void {
    echo QrCode::terminal($event['qr']);
});

try {
    $client->connect();
    $client->run();
} finally {
    $client->disconnect();
}
receber.php
<?php
require __DIR__.'/vendor/autoload.php';

use MVO\WaClient;

// Use uma sessão já vinculada.
$client = new WaClient(
    sessionId: 'minha-sessao',
    authDirectory: __DIR__.'/var/whatsapp-auth',
);
$client->on('message', static function (array $event): void {
    $text = $event['text'] ?? null;
    if (is_string($text)) echo $text.PHP_EOL;
    // Use sessão, chat e ID para evitar repetir ações externas.
});

try {
    $client->connect();
    $client->run();
} finally {
    $client->disconnect();
}
enviar.php
<?php
require __DIR__.'/vendor/autoload.php';

use MVO\WaClient;

// Use uma sessão vinculada e substitua o destinatário fictício.
$client = new WaClient(
    sessionId: 'minha-sessao',
    authDirectory: __DIR__.'/var/whatsapp-auth',
);
try {
    $client->connect();
    while ($client->isRunning()) {
        $client->poll(0.5);
        if (!$client->isConnected()) continue;

        $result = $client->sendText('5511999999999', 'Olá pela MVO!');
        echo 'Aceita pelo servidor: '.$result['id'].PHP_EOL;
        break;
    }
} finally {
    $client->disconnect();
}

Encerre o primeiro processo antes de executar outro exemplo com a mesma sessão. connect() inicia ou restaura a conexão; run() e poll() mantêm o processo ativo. No envio, aguarde isConnected(); server_ack confirma aceite no servidor. Entrega e leitura são acompanhadas pelos recibos.

Uma instalação, várias sessões

Cada conta usa seu próprio sessionId e um subdiretório de credenciais. A mesma instalação da biblioteca atende várias contas, com um worker persistente e lock exclusivo por sessão ativa.

Retome sem gerar outro QR

Mantenha o mesmo ID e a mesma pasta ao reiniciar. disconnect() preserva o vínculo válido; logout() desvincula o aparelho. Guarde var/whatsapp-auth fora da raiz HTTP pública e do Git.

Para uma API, encaminhe comandos ao worker que já possui a sessão. Os listeners recebem eventos; envios e consultas ao WhatsApp acontecem no loop externo, depois dos callbacks. Veja o guia da primeira integração e os eventos de conexão e QR.
