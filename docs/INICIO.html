Conecte o WhatsApp.
Construa em PHP.

Crie uma sessão, acompanhe o QR e troque mensagens pela biblioteca MVO. Integre os eventos ao fluxo da sua aplicação.

Começar integração Explorar API
  • PHP 8.2+
  • QR ou código
  • Sessão persistente
conectar.php
<?php
require 'vendor/autoload.php';

use MVO\WaClient;
use MVO\Auth\QrCode;

$client = new WaClient('minha-sessao');
$client->on('auth_qr', function (array $event) use ($client): void {
    file_put_contents(
        $client->sessionDirectory().'/qr.svg',
        QrCode::svg($event['qr'])
    );
});

try {
    $client->connect();
    $client->run();
} finally {
    $client->disconnect();
}
receber.php
<?php
require 'vendor/autoload.php';

use MVO\WaClient;

// Use uma sessão já vinculada.
$client = new WaClient('minha-sessao');
$client->on('message', function (array $event): void {
    $text = $event['text'] ?? null;
    if (is_string($text)) echo $text.PHP_EOL;
    // Use chat e ID para evitar repetir ações externas.
});

try {
    $client->connect();
    $client->run();
} finally {
    $client->disconnect();
}
enviar.php
<?php
require 'vendor/autoload.php';

use MVO\WaClient;

// Use uma sessão vinculada e substitua o destinatário.
$client = new WaClient('minha-sessao');
try {
    $client->connect();
    while ($client->isRunning()) {
        $client->poll(0.5);
        if (!$client->isConnected()) continue;

        $result = $client->sendText('5511999999999', 'Olá pela MVO!');
        echo 'Aceita pelo servidor: '.$result['id'].PHP_EOL;
        break;
    }
} finally {
    $client->disconnect();
}

Da primeira sessão à sua aplicação.

Prepare o ambiente, vincule o aparelho e mantenha o processo PHP ativo para acompanhar as mensagens.

  1. Prepare seu ambiente

    Instale as dependências e configure as extensões do PHP.

  2. Conecte uma sessão

    Acompanhe cada QR ou solicite um código de vinculação.

  3. Envie e receba

    Ouça o evento de mensagem e envie depois que a conexão estiver pronta.

  4. Retome quando precisar

    Reabra com a mesma sessão e pasta para restaurar um vínculo válido.
